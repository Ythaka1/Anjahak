Design system rules for AnjaHak:
- Colors: always use CSS variables (--earth, --forest, --canopy, --harvest, --gold, --dusk, --parchment)
- Never hardcode hex colors in components
- Fonts: Cormorant Garamond for display/italic, Playfair Display for headings, DM Sans for body, Space Mono for labels
- Buttons: amber filled (primary), ghost outline (secondary), underline ghost (tertiary)
- Cards: white background, border-radius 1.5rem, box-shadow card style, overflow hidden
- Section backgrounds alternate: parchment → dusk → parchment → forest (dark)
- Every section has a small uppercase Space Mono label above the heading
- Grain texture overlay on hero and dark sections
- Mobile first always
